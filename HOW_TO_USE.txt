====================================================
TLA2528 Arduino Library - Installation Instructions
====================================================

IMPORTANT: File Extensions
---------------------------
The .cpp files ending with example names are actually Arduino sketches.
They are saved as .cpp so you can preview them in the browser.

To use them in Arduino IDE:
1. Rename files from .cpp back to .ino:
   - TLA2528_AnalogReadSerial.cpp → TLA2528_AnalogReadSerial.ino
   - TLA2528_DigitalReadWrite.cpp → TLA2528_DigitalReadWrite.ino  
   - TLA2528_Basic_Example.cpp → TLA2528_Basic_Example.ino

INSTALLATION METHODS
--------------------

Method 1: Arduino Library Manager (After Publishing)
1. Open Arduino IDE
2. Sketch → Include Library → Manage Libraries
3. Search for "TLA2528"
4. Click Install

Method 2: Manual Installation
1. Download all files
2. Create folder: Arduino/libraries/TLA2528
3. Copy all files maintaining the structure above
4. Restart Arduino IDE

Method 3: ZIP Installation
1. Create a ZIP with the folder structure above
2. Arduino IDE: Sketch → Include Library → Add .ZIP Library
3. Select your ZIP file

WIRING REQUIREMENTS
-------------------
- VCC: 3.3V (2.7V to 5.5V supported)
- GND: Ground
- SDA: I2C Data (needs 4.7kΩ pull-up to VCC)
- SCL: I2C Clock (needs 4.7kΩ pull-up to VCC)
- A0: Address select (GND=0x10, VCC=0x11)

IMPORTANT: The TLA2528 has NO internal pull-up resistors!
- Add 10kΩ pull-ups for button inputs
- Add 4.7kΩ pull-ups on I2C lines

BEFORE PUBLISHING
-----------------
1. Update author name and email in library.properties
2. Update copyright in LICENSE file
3. Update GitHub URLs in README.md
4. Create GitHub repository
5. Tag your release (e.g., v2.0.0)
